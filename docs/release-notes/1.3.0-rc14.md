# GT4Recomp 1.3.0-rc14 (test build)

**A test release candidate of 1.3.0: camera zoom in races, an optional finer trigger range, Spec II's speed and timer text kept
in shape on wide screens, a first-start note for creating your save, and the Spec II PT-BR image with Gran Turismo PSP cars
recognised. The race itself is unchanged.**

## New

- **Camera zoom in races (TASK-160, both games, on by default).** Hold R3 and press up or down on the D-pad to zoom the race
  camera in or out, one step per frame, from half to twice the game's view; L3 + R3 resets it. The zoom scales the projection the
  game itself builds for its race cameras, with the game's own divide, so at the normal view nothing changes; the race clock stays
  the same while zooming. In races the game does nothing else with these buttons. `fov_adjust=0` in `game.ini` (or
  `GT4_FOV_ADJUST=0`) turns it off. Idea from the community PCSX2 patch, used as a reference only.
- **Full trigger range (TASK-161, experimental, off by default).** The game turns a trigger's pressure into its own coarse scale:
  46 throttle levels with 100% at a pressure of 45 out of 255, and 85 brake levels with 100% at 84 (our controls already stretch
  the trigger travel over those, TASK-147). With Controls > "Full trigger range (experimental)" on, the throttle and brake follow the whole travel in about 254 levels, still reaching 100%
  at the end. Off is the game as it was made; the owner decides its default after a test.
- **First-start note on Play (TASK-164, issue #160).** On a new card Gran Turismo 4 first asks whether to create its game data,
  and only Cross answers; players who pressed another key thought the game had frozen. When the selected game has no save yet
  (none in the launcher's library, none on the card the game left behind), Play now shows a short note before the game starts:
  confirm with Cross, named with the keys of your own controls (W or Enter on the keyboard and A on a controller by default), and
  when a question starts on Cancel or No, move to Yes or OK first. Play starts the game; Cancel starts nothing. The note is gone
  once the save exists.
- **Spec II PT-BR + CPSP image (TASK-167).** The Brazilian Portuguese Spec II image with some cars replaced by Gran Turismo PSP
  cars is recognised by name. Its game program is the same as Spec II 1.10's, and every file but the game data volume is
  identical to the PT-BR image, so it ran before as an unnamed "variant"; a recorded lap on it matches the PT-BR image frame for
  frame.

## Fixes

- **The 360 camera also stopped a left-stick or wheel throttle (TASK-159b).** While the camera is on, only the right stick's
  up and down no longer accelerate and brake; a throttle or brake set on the left stick or on a wheel's pedals works again.
- **Spec II on screens wider than 16:9 stretched the speedometer, the odometer and the lap timer (TASK-166).** Gran Turismo 4
  draws that text with a font whose width it sets for a 16:9 screen; our ultrawide support corrects that width (and the rear-view
  mirror's) on v2.00, but the correction had not been carried over to Spec II. The same two instructions are now corrected in
  Spec II. At 16:9 nothing changes: every compared frame is identical to rc13.

## Checks

On this build (plain, no profile-guided optimisation; the published build of a release candidate gets it):

- **Spec II against rc13:** the race clock at every VBlank and the whole simulation state identical on three recorded laps
  (George V Paris, El Capitan, Tokyo R246), and every compared frame identical (35 of 35 on each).
- **Launcher:** 661 tests, focus checks in both languages, navigation tests; locale keys identical in en-US and pt-BR.

## Known issues

- **Photo mode on slower graphics cards (CoreGS 2.0):** each picture still waits for the graphics card twice, so frame times can
  be uneven (TASK-162).
