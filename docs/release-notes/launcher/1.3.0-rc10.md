# GT4Recomp 1.3.0-rc10

**Fixes for problems players reported: Spec II replays are kept, the game runs without a sound device, and memory card backups no longer fill your disk.**

## Fixes
- Spec II replays you save are kept: before, they disappeared after the game was closed.
- The game no longer closes on a PC without a sound output device: it runs without sound.
- The bubbling sound of the oil change and the car wash in GT Auto stops when the service ends.
- Memory card backups no longer pile up: the launcher keeps the latest 10 copies of each game's card (before, every Play added about 8 MB for good).
- If GSdx is not installed, for example because its download was blocked, Play offers CoreGS 2.0 instead of stopping.
- When the game closes on its own, the launcher says why in plain words; if the memory card cannot be prepared, the message names the file.

## Performance
- The graphics' vertex math takes about 3% less time, with the same results (automated runs).

## Good to know
- Races always run at 480p, also with a save that was set to 1080i.
