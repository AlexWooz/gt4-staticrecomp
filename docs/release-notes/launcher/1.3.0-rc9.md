# GT4Recomp 1.3.0-rc9

**A big step for weaker processors: the game uses about 18% less processor on an old laptop, with the same physics and the same picture.**

## Performance
- About 18% less processor work per frame on an i5-7200U laptop, in a race on George V Paris with CoreGS 2.0 at 1x: from 33.9 ms to 27.6 ms (automated runs).
- About 19% less on a Ryzen 7 5700X, in the same race: from 12.6 ms to 10.1 ms.
- The game's own translated code runs about a third faster, thanks to a build tuned from real races.
- Spec II no longer interprets part of its math: that code now runs compiled, as on Gran Turismo 4.

## Good to know
- Nothing changes in the game itself: over a whole lap the race clock and the car physics stayed identical to the previous version, byte for byte.
- This test build needs no new setup: your settings and saves stay as they are.
