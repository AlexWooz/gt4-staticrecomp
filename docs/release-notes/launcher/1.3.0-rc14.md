# GT4Recomp 1.3.0-rc14

**Spec II's speed and timer text no longer stretch on wide screens, and the first start explains how to create your save.**

## New
- The first time you play a game with no save yet, Play tells you which key confirms the memory card questions (W or Enter on
  the keyboard, A on a controller, by default).
- Spec II: the Brazilian Portuguese disc image with Gran Turismo PSP cars (PT-BR + CPSP) is recognised by name.

## Fixes
- Spec II on screens wider than 16:9 (21:9, 32:9): the speedometer, the odometer and the lap timer keep their
  shape instead of stretching, as in Gran Turismo 4.
