# GT4Recomp 1.3.0-rc12

**No more desktop flash every few seconds in fullscreen, and on CoreGS 2.0 a race now keeps its full speed when the PC cannot hold 60 FPS.**

## New
- On CoreGS 2.0, 60 FPS lets the frame rate drop in a race when the PC cannot keep up, instead of slowing the game down. The physics stay the same, and with time to spare every frame is drawn (experimental; menus stay as before).

## Fixes
- In fullscreen, mainly on NVIDIA RTX cards, the desktop or the window behind the game no longer flashes for a frame every few seconds, with a stutter. This happened on CoreGS 2.0 and GSdx alike.
- After Alt+Tab, the game no longer comes back as a white "Not responding" window.
