# GT4Recomp 1.3.0-rc16

**The game no longer compiles graphics shaders during a race: the launcher prepares them before the start, now for the
render scale you chose.**

## New
- Changing the Render scale: the launcher now prepares the graphics shaders for the size you chose before the game
  starts, instead of leaving part of a 4x race on a slower general shader.

## Fixes
- The game no longer compiles a shader during a race. When an effect needs a shader it does not have, it is drawn with
  the general shader (the same picture) and the next Play prepares it. This removes the freeze of up to one second in
  the middle of a lap, and the crash a player met at 4x.
- After a race records a new effect, the next Play prepares it: before, the launcher thought the preparation was still
  up to date.

## Performance
- A 4x race prepared for 4x no longer falls back: about 1.9 ms less graphics work per frame in a recorded Paris race
  (5.7 to 3.8 ms), with the same picture.
- 39 more shaders prepared for 4x on our test card.

## Good to know
- This test build is Gran Turismo 4 v2.00 only: Spec II is not included, and installing it removes Spec II from the game
  folder until a build that ships it.
- It is not the optimised rc15 build: this one is for testing the new shader behaviour, so it may be a little slower in
  races.
- The first Play after changing the Render scale, or after this update, prepares the shaders once.
- Your Gran Turismo 4 v2.00 saves and settings are kept.
- If something looks wrong, tell us which Render scale and scene you were in, and send the logs from the launcher.
