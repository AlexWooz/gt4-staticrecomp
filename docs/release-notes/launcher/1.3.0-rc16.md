# GT4Recomp 1.3.0-rc16

**Both Gran Turismo 4 v2.00 and GT4 Spec II are in this test build, with a shader preparation that now knows far more of what
both games draw and the render scale you chose.**

## New
- Both games are in this build: GT4 v2.00 and GT4 Spec II, each with its own program and the same graphics preparation.
- About 100 more shader states, recorded from both games, now start already prepared: photo mode, license tests, showrooms,
  night and wet tracks, and several car body materials no longer fall back to the slower general shader when they appear.
- Changing the Render scale: the launcher now prepares the graphics shaders for the size you chose before the game starts, so
  a 4x race no longer starts without part of its shaders.

## Fixes
- The game no longer compiles a shader during a race. When an effect needs a shader it does not have, it is drawn with the
  general shader (the same picture) and the next Play prepares it. This removes the freeze of up to one second in the middle
  of a lap, and the crash a player met at 4x.
- After a race records a new effect, the next Play prepares it: before, the launcher thought the preparation was still up to
  date.

## Performance
- A 4x race prepared for 4x no longer falls back: about 1.9 ms less graphics work per frame in a recorded Paris race (5.7 to
  3.8 ms), with the same picture.
- The same on a recorded v2.00 night race at 4x: about 1.6 ms less per frame (5.7 to 4.2 ms).
- 70 more shaders prepared for 4x on our test card (245 instead of 175).

## Good to know
- This is the optimised build: both games are compiled with profile-guided optimisation and thin link-time optimisation,
  as rc15 was. In our 4x test race a frame took 7.4 ms instead of 8.4 ms (about 12% less), with the same picture.
- The first Play after changing the Render scale, or after this update, prepares the shaders once.
- Your Gran Turismo 4 saves and settings are kept, and so is your Spec II setup.
- Not every part of both games has been recorded yet: split screen, replays, Spec II GT Mode races and Spec II photo mode are
  not in this preparation. If an effect appears with the general shader, the next Play prepares it.
- If something looks wrong, tell us which game, which Render scale and which scene you were in, and send the logs from the
  launcher.
