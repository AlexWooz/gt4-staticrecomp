# GT4Recomp 1.3.0-rc10

**Correções para problemas relatados pelos jogadores: os replays do Spec II ficam salvos, o jogo roda sem dispositivo de som e os backups do memory card não lotam mais o seu disco.**

## Correções
- Os replays do Spec II que você salva ficam guardados: antes, eles sumiam depois de fechar o jogo.
- O jogo não fecha mais num PC sem saída de som: ele roda sem áudio.
- O som de bolhas da troca de óleo e da lavagem no GT Auto para quando o serviço termina.
- Os backups do memory card não se acumulam mais: o launcher guarda as 10 cópias mais recentes do cartão de cada jogo (antes, cada Jogar somava cerca de 8 MB para sempre).
- Se o GSdx não estiver instalado, por exemplo porque o download foi bloqueado, o Jogar oferece o CoreGS 2.0 em vez de parar.
- Quando o jogo fecha sozinho, o launcher explica o motivo em palavras simples; se o memory card não puder ser preparado, a mensagem diz qual arquivo falta.

## Desempenho
- As contas de vértices dos gráficos levam cerca de 3% menos tempo, com os mesmos resultados (rodadas automáticas).

## Bom saber
- As corridas sempre rodam em 480p, mesmo com um save configurado em 1080i.
