# GT4Recomp 1.3.0-rc9 (test build)

**A test release candidate of 1.3.0 for one thing: the CPU. The game side (EE, VU, IOP, runtime) and the build around it use less processor, with the game itself unchanged. It adds no options.**

## What changes

Numbers are the owner's recorded lap on George V Paris, Spec II, CoreGS 2.0 at 1x, headless. "Player's session" is a run with no report on, milliseconds of processor per VBlank for the whole process; rc8 and rc9 are interleaved.

| | i5-7200U / HD 620 | Ryzen 7 5700X / RX 9060 XT |
|---|---|---|
| Whole process CPU, player's session | 33.87 -> 27.64 ms (-18%) | 12.59 -> 10.14 ms (-19%) |
| Wall per VBlank without pacing, player's session | 15.77 -> 14.48 ms (-8%) | 5.88 -> 5.43 ms (-8%) |

With the F7/F8 report's scopes on, second round of each build on the i5-7200U, then the same on the 5700X:

| | i5-7200U | Ryzen 7 5700X |
|---|---|---|
| EE thread CPU | 13.15 -> 9.44 ms | 4.13 -> 2.91 ms |
| Translated game code (`ee_dispatch`) | 7.28 -> 4.92 ms | 2.45 -> 1.55 ms |
| VU1 program | 10.82 -> 8.72 ms | 3.28 -> 2.93 ms |

On the laptop the frame in this scene is limited by the GS thread and the integrated GPU (about 19 ms): the processor work fell more than the frame.

- **Profile-guided optimisation and ThinLTO of the whole game,** where rc8 had them only on the GS libraries: VU AOT code, runtime, VU1 worker, host loop, and the EE library rebuilt from the same translated units with one compiler and SSE4.1. Trained on full races of each game.
- **The exact PS2 FPU maths:** the VU0 macro operations compute four lanes at once with SSE4.1, and `fp::add`, `fp::mul` lost the branches a processor cannot predict. The bits are the same: every combination of exponents, 400 million random pairs and the macro operations against their definition (`native_vu_fast_ops`).
- **Spec II VU0 microcode runs compiled:** it ran in the exact interpreter on most calls (3.1 million in one lap), because only v2.00 had its programs generated. Now 0 interpreted calls, on the same differential tests.
- **VU1:** the clamp `vfix` (proved over all 2^32 values) and the MAC flags (compared with the scalar form) in faster exact forms.
- **The measuring itself:** with the performance report off, a session reads no clock for the F7/F8 scopes, the renderer's stage times or the draw pass timestamps. With it on, the scopes read the processor's counter directly, about a third of the cost. The stage times in the `[core2]` lines read 0 without the report, and the F7/F8 report needs Settings' performance report on, as before.
- **Small things on the VU1 worker's path:** doorbell statistics without a locked add, and one record buffer kept instead of allocated per job.

## Same game

Against the rc8 executables, on this build:

- **Physics:** the race clock at all 8,030 VBlanks and the whole simulation state at VBlank 8000 of the lap, byte for byte (Spec II); the same on the v2.00 night race with 5 AI cars, 12,097 VBlanks, state at VBlank 10000.
- **Frames:** 10 of 10 at 3x (v2.00 night race), 14 of 14 (v2.00 Arcade path), 12 of 12 at 6x (Spec II lap).
- **Checks while running:** compiled VU1 programs against the exact interpreter, 236,448 samples on Spec II and 355,388 on v2.00, 0 differences; VU0, 39,731 samples, 0 differences; the MTVU check over 8,032 frames, 0 differences.

## Known issues and limitations in this test build

- **A small dark rectangle for one frame, on rc8 too:** on the lap at VBlank 3750, a block of about 16 x 7 pixels of a track sign is sometimes drawn dark, about 1 run in 6 on rc8 and on rc9 alike (2 of 12 each). It depends on timing, the simulation is unaffected, and the cause is not known yet.
- **Not measured in a real session yet:** all of the above is headless. The owner's test on the desktop and the notebook comes next.
- **Everything else** is unchanged from rc8, including its known issues.

## Install or test

- **Installer:** run `GT4Recomp-Setup-1.3.0-rc9.exe`. It keeps existing settings, saves and replays.
- **Portable:** unpack `GT4Recomp-1.3.0-rc9-portable.zip` anywhere. Settings, saves and data stay inside the folder.
- **Disc images:** you need your own: Gran Turismo 4 (USA, v2.00), and your own Spec II 1.10 image for the mod. GT4Recomp ships no copyrighted game files.

## Requirements

Windows 10 or 11, 64-bit, a processor with SSE4.1. CoreGS 2.0 needs a graphics card with Vulkan 1.2.
