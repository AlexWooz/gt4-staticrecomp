  caller's guest read function, so the fixture drives hand-authored chains. The K1 post hook now walks every hooked

- **The carried block (H).** `ps2::Cpu` has no VU1 memory; the VU1 data memory is `g_vu1_mem[16384]`, owned by the MTVU

  two-slot model predicts all 158 carried blocks of frame 0; the 5 uncertain labels are conservative. The smallest exact
  alternative (a `run_vu` hook in a new pinned runtime capsule) is written down, not implemented.
