  `GT4_HW_SCALE` at construction; GSdx is a separate process).
- Implemented in `native/window.cpp`: `apply_display_mode` (enumerate the monitor, prefer the current refresh, save the
  original `DEVMODE`, `ChangeDisplaySettingsExW(CDS_FULLSCREEN)`, window to the new `rcMonitor`),
  `restore_display_mode` (fullscreen Off, WM_DESTROY, cleanup), `apply_output_size` (fullscreen display mode or
  windowed `AdjustWindowRectEx` + `SetWindowPos`), and the start apply from `GT4_OUTPUT_SIZE`.
