- **TASK-189: the launcher's Wheel page after the owner's G27 test of the rc15 draft (owner, 2026-11-06).** Branch
  `task/189-wheel-page-polish` from `release/1.3.0-rc15` at 110cacad; one writer; no PR, no release build (the orchestrator rebuilds
  the installer after this and TASK-188). His verdict: the wheel drawing and the buttons are right and are not touched; the rest
  of the page follows six points.
  - **Mapping is one action.** A click on a control of the drawing, its Map button or A on the pad opens the capture popup at
    once (before: click the chip, then Atribuir in the panel). The popup is named for the control, shows what it presses on the
    DFP, waits for the button/axis/pedal, offers Clear in the same popup, and closes on Esc, B, Cancel or Y (pad clear). A click
    on the empty drawing only selects (`wheel-svg.js` reports whether the click landed on a control).
  - **No guessed mapping.** `WheelConfig::unassigned()` (every source empty, the game's calibration numbers kept) is what a
    missing or refused `wheel.toml` loads and what Reset produces; `wheel_identity::template("generic")` returns it too, so an
    unknown wheel is never pre-filled with axis 0 and the D-pad. The game's own parser fallback (`WheelConfig::default`,
    `native/wheel.cpp`) stays as it was: it is the file format, not the launcher's starting point.
  - **The shipped G27 preset.** `crates/gt4l-core/assets/wheel-presets/logitech-g27.toml` holds the owner's mapping
    (`046D:C29B`); `wheel_identity::BUILTIN_PRESETS` lists it by USB IDs and `builtin_preset_config` reads it with the game's
    parser. `wheel_page::auto_apply_builtin` applies it when there is no file and the detected device matches, at the page and at
    Play, and the view reports `applied_preset` so the page can say it. Generic mechanism: one table entry per wheel.
  - **Cards.** The "Your wheel" card is gone (name in the badge; the 900-degree advice is the Rotation row's tooltip); the badge
    shows "Connected" without the USB ID. What is left of that block is the wheel-the-game-uses dropdown when several devices are
    present and the mode warnings, in a compact block that hides itself when empty. The force feedback card got one compact result
    line under Test force (green when played, amber when refused) and its "in the last game" row is drawn only when the game
    reported it (the "unknown" row is gone). Checked at 1366x768 and 1920x1080.
  - **The on/off switch is gone.** `prepare_for_play` (called from `prepare_play` with the pad service's `wheel-status`) plugs the
    virtual DFP in exactly when the status lists a wheel (`wheel_service::wheel_connected`: role `wheel` or `other_wheel`; `None`
    when SDL3 did not list anything) and writes and logs the decision; with no device list the stored value is kept. The stored
    `[wheel] enabled` of an rc15 file stops being a player setting: it is derived at Play, so the old key's value does not survive
    a Start (logged).
  - **Tests.** `cargo test --workspace`: 284 gt4l-core (wheel 32 of them, new: the G27 preset's shipped file and identity entry,
    the unassigned start and its round trip, `is_unassigned`), gt4l-tauri 143 + 2 new flow tests (the G27 auto-preset and the
    unknown wheel's empty start; Play's per-Start on/off, the dropped stored value and the SDL3-unavailable case) and unit tests
    for `main_device`, `reset_template` and `wheel_connected`. One failure,
    `flow_audit::a_1_2_x_install_moves_into_games_gt4_at_the_first_start`, is environmental: a `gt4vulkan.exe` was running on the
    machine, so the large-data move refuses by design ("large data: not moved now (Gran Turismo 4 is running)"). Focus checks
    en-US 368/368 and pt-BR 375/375, nav-test 260/260, locale keys 913 in both languages (the removed keys are gone from both
    files; new keys: the preset notice, the popup title/hint, the pointer/key hints, "Connected").
  - **Evidence.** `build/evidence/t189/`: en-US and pt-BR at 1366x768 with a mocked G27 and with an unknown wheel, the popup, the
    force feedback card, and 1920x1080. Owner test of the next rc15 build (with TASK-188) pending.
