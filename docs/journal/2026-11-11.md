- Read-only study. No game code, build, pin, save or card changed. Worktree
  `O:\Antigavity\gt4-wt-104-hshifter-study`, branch `task/104-hshifter-study`, based on `main` `85718831`.
- Read the current input path (`native/host_io.cpp`, `native/pad_mapping.*`, `native/controls.*`,
  `native/window.cpp`, donor `iop/sio2.cpp`), the wheel work on the 1.3.0-rc15 line (`docs/WHEEL.md`,
  `docs/WHEEL-NATIVE-DFP.md`, `native/usb_dfp.cpp`, `native/wheel.cpp`, TASK-121/123/181/192) and the decomp
  `private/slice151-research/gt4-decomp` at `e0b70c4d6`.
- Findings (details and labels in `docs/H-SHIFTER-CLUTCH-STUDY.md`):
  - GT4's input actions are sequential shift up/down and reverse; no clutch action and no H-gate action in the
    ELF action table. The DFP input report (8 bytes) has steering, 14 buttons, hat, throttle and brake; no
    clutch or gate. The rc15 wheel work says direct gear selection and manual clutch are outside its scope.
  - The HUD does have `setGear`, `setClutch`, `setAutomaticTransmission` and `setShiftTimingLamp` (Confirmed
    symbols). The clutch flag's source and any drivetrain clutch torque are Unknown; the matched decomp has no
    clutch physics symbol.
  - MT/AT: `Automobile__isFullManualTransmission` (0x003481C8) reads `Automobile + 0x546 == 6`; called from
    `RaceBase::initializeDynamicsConductor` (0x00388790, call at 0x00388844) and from `func_0037AD40`
    (call at 0x0037AD70).
  - Gear-selection candidate: `func_0037AD40` / `func_0037ACD0` / `func_0037AD10` / `func_0037BC20` /
    `func_0037BC68`, with a 12-entry table at `0x006211E8` and a gear field at `+0x180`. The code path is
    high confidence; the player-car ownership and the physics gear field are Unknown.
  - Input path: host -> `ps2::set_pad_buttons` -> SIO2 HLE -> game. The `RaceInput` singleton is at
    `0x00622B60`; its pad word is at `0x00622CE8`. A VBlank guest-RAM hook already exists
    (`widescreen_hold_at_guest_vblank` in `vblank_sync`), but a direct gear write is a mod and is not
    recommended.
- Recommendation: implement H-shifter as button emulation first (pad R2/L2 on main, DFP R1/L1 on the rc15 wheel
  branch), with a pure shift sequencer and the game's own rules; add a read-only gear probe only if needed; do
  not implement direct gear writes or a clutch in the first version.
