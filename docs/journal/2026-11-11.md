# 2026-11-11

## Gameplay mods move into the bundle (owner, 2026-11-11)

The owner decided (Telegram) that gameplay modifications ship in the same bundle as the recompiled port: the H-shifter
with direct gear application, reverse as a gate position (R, N, 1, 2, ...), and a clutch pedal with a clutch system.
The original game already runs, so the project now also "plays around more": mods are opt-in, off by default, and with
every mod off the game is identical to the reference. Recorded as `docs/decisions/0073-mod-support-in-bundle.md`; the
`AGENTS.md` mission and game-patch rules were scoped accordingly (patches leave gameplay alone; mods change it, opt-in).

TASK-215 (H-shifter, clutch, direct gears) is now a mod task of this repository; its deep study (transmission/clutch
physics map, direct gear path, pedal input plumbing, PoC plan) is in progress on `task/215-hshifter-deep`.
