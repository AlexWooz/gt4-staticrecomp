- **TASK-182 step 2c (the deinterlace decision).** The step 2b plan ("decide once per native pixel at 1x, resolve per
  output pixel") was tested before being implemented and dropped: it is not a refactor of today's kernel, it is a
  different deinterlace. Two facts.
  - `PlanDeinterlace` sets `rowStep = 1` unless `GT4_HW_DEINTERLACE_ROWS=native` (IN-386), so the algorithm row is one
    *output* row and the rows a decision compares are sub-rows of the same native pixel; a decision per native pixel is
    the IN-381 native-rows reading that IN-386 replaced (the owner's doubled menu lines).
  - The composed image at 10x is not block-constant: 46.7% of the 640x448 native blocks are one colour at VBlank 1200
    (`core2_compose.comp` is a 1:1 copy of the internal-scale render). Replaying mode 6 on the four real merge images
    (dumps 1197..1200 with the deinterlace off) shows 1.46% of native blocks with a decision that is not constant inside
    the block, and **69,608 of 14,329,600 missing-row pixels (0.49%) change their word** if one decision per native pixel
    is applied - so it fails a bit-identity gate by construction, not by accident.
  - What shipped instead is the provably dead part of the same decision, `GT4_CORE2_DEINT_SKIP_DECISION=1`: modes 5 and
    6 end in `bob` or the woven row, and `interpolate` is known before any test runs, so the invocation stores the word it
    already has and returns when both branches give it (`!interpolate`, or `bob == woven`). 46.5% of the missing-row
    pixels take that path on the measured menu frame.
  - Times (desktop, shared with an Android emulator, ms/VBlank, indicative): 480i menu 10x deinterlace 5.09 -> 3.10 (-39%)
    and `gpu_busy` 8.21 -> 6.14 (-25%) in today's order; with step 2b's field compose 4.61 -> 2.69 (-42%), busy 7.90 ->
    6.04; 2x 0.215 -> 0.155 and 0.17 -> 0.125 with the compose. Races (480p) unchanged.
  - Identity: `hw_core2_post_field_compose` extended to the four switch combinations at 1x, 2x, 3x and 10x (adaptive rule
    6, weave, bob, progressive; 0 differing of 32,768 / 131,072 / 294,912 / 3,276,800 pixels per case, and the stream now
    has a flat band so the skip path runs); menu dumps at 2x and 10x (VBlanks 1200/1500) identical in all four
